# Gameplay Preview Clips Directory

Drop your short, muted gameplay clips (`.mp4` or `.webm`) here.
Previews are lazy-loaded on hover, crossfade in 200ms with no audio, and auto-pause when mouse leaves.

### Recommended Spec:
- **Resolution**: 480p to 720p (aspect ratio 4:3 or 16:10, e.g. 640x480 or 854x480)
- **Duration**: 5 - 8 seconds, seamless loop
- **Audio**: None (tracks are muted in playback)
- **Size**: Under 2 MB per clip
