=====================================================
RENEarn Studio - Minecraft Live Connector Plugin
Version: 1.2.0 (Spigot / Paper / Purpur / Fabric)
=====================================================

HOW TO INSTALL:
Option A (Spigot / Paper / Purpur Server):
1. Place "RENEarnMinecraftPlugin.jar" into your server's "plugins" folder.
2. Start or reload your Minecraft server.
3. RENEarn Studio will automatically connect and dispatch live events!

Option B (Fabric / Forge Client with ServerTap):
1. Install ServerTap mod into your mods/ directory.
2. Configure port 8080 in ServerTap config.
3. Launch Minecraft and start streaming!
