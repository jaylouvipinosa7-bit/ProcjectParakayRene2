===============================================================================
             RENEarn • APPLICATIONS & LAUNCHERS DIRECTORY
===============================================================================

This folder contains the core application executables and startup scripts:

1. RENEarn_Studio.exe
   - Standalone desktop application window with low-level hotkey integration.
   - Automatically boots the background streaming services and opens the studio dashboard.

2. PvZ_Fusion_Studio.exe
   - Dedicated launcher for Plants vs. Zombies Fusion livestream streams.

3. Launch_Studio.bat
   - Clean batch script alternative for launching the studio server & web client.

4. create_desktop_shortcut.ps1
   - Generates a 1-click desktop shortcut on your Windows desktop.
===============================================================================
