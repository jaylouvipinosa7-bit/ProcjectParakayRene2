===============================================================================
 KINGDOM SIEGE - TIKTOK LIVE INTERACTIVE CASTLE DEFENSE
===============================================================================

Welcome to Kingdom Siege! A real-time, interactive stream defense game built
specifically for TikTok LIVE Studio and OBS Studio.

HOW TO START:
1. Double-click "Launch_Kingdom_Siege.bat"
2. The game opens in a dedicated window ready to play.
3. In OBS / TikTok LIVE Studio, add a Browser Source pointing to:
   http://localhost:8080/kingdom-siege.html

STREAM SETTINGS:
- Horizontal (16:9 / 1920x1080): Standard OBS / YouTube / Twitch
- Vertical (9:16 / 1080x1920): Click the "Vertical" toggle button at the top

STREAMER DEFENSES:
- Click anywhere on the battlefield to fire Mortar Cannons!
- 4 Ultimate Skills (Bottom Left):
  * Cannon: Mortar AOE cluster
  * Blizzard: Freezes all enemies for 4.5 seconds
  * Meteor: Apocalypse rain from the sky
  * Repair: Heals fortress gates and casts a golden shield

TIKTOK VIEWER ACTIONS:
- Free Likes / Comments  : Spawns Goblin Scout swarms
- Rose (1 coin)          : Spawns Orc Berserkers
- Heart / Ice Cream      : Spawns Armored Battering Rams
- Donut (30 coins)       : Spawns Dark Trebuchet Catapults
- Dragon / Swan          : Spawns Flying Shadow Dragons
- Galaxy / Lion / Whale  : Summons the COLOSSAL TITAN BOSS!

All spawned monsters display the viewer's TikTok avatar and username!
Live MVP board tracks the top siege commanders in real-time.
